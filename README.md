# 🚢 B站舰长礼物小助手

> 给 B站主播用的小工具：**自动确认谁是你的舰长，并帮你收集舰长的收货地址和手机号**，月底直接导出一张表去寄礼物。
>
> 不会写代码也能用 —— 跟着下面的步骤一步一步来就行。

---

## 它能帮你做什么？

想象一下你以前是怎么做的：观众上舰 → 加群 → 你一个个看截图 → 一个个私聊要地址 → 抄到表格里……很累，还容易漏。

用了这个小助手之后：

| 以前你要做的 | 现在谁来做 |
|---|---|
| 看截图确认是不是舰长 | 🤖 QQ 机器人自动识别截图，还会去 B站 核对舰长名单 |
| 记下每个人哪天上的舰 | 🤖 机器人自动从截图里读出日期并记录 |
| 私聊要地址、手机号 | 🤖 机器人发给舰长一个专属链接，舰长自己填 |
| 舰长说“我搬家了要改地址” | 🤖 机器人听得懂，会先问几个问题确认他是**本月**舰长，再给他改 |
| 整理发货名单 | 🖥️ 在后台网页点一下「导出发货表」，用 Excel 打开就是完整名单 |

你只需要偶尔在后台点一下「通过」（机器人拿不准的人会交给你确认），然后照着表格寄礼物就好。

## 开始之前，你需要准备

- ✅ 一台 **Windows 电脑**（以后想 24 小时运行，可以换成云服务器，见文末）
- ✅ 一个 **QQ 小号**，专门当机器人（别用大号，有被风控的可能）
- ✅ 你的 **B站直播间号**（直播间网址 `live.bilibili.com/` 后面那串数字）
- ✅ 大约 **30 分钟** 时间

## 安装步骤（第一次用跟着做）

### 第 1 步：安装 Python

Python 是运行这个工具需要的软件，装一次就行。

1. 打开 https://www.python.org/downloads/ ，点黄色的 **Download Python** 按钮下载
2. 双击安装包，**⚠️ 一定要先勾选最下面的「Add python.exe to PATH」**，再点 **Install Now**
3. 装好后按 `Win + R`，输入 `cmd` 回车，在黑色窗口里输入下面这行并回车：
   ```bash
   python --version
   ```
   看到 `Python 3.xx.x` 就说明装好了 🎉

### 第 2 步：下载本工具

1. 在本页面上方点绿色的 **`<> Code`** 按钮 → **Download ZIP**
2. 把下载的压缩包**解压**到一个好找的地方，比如桌面
3. 打开解压后的文件夹，能看到 `bot.py`、`启动.bat` 等文件就对了

### 第 3 步：安装需要的组件

1. 打开刚才解压的文件夹
2. 在文件夹**地址栏**里输入 `cmd` 然后回车，会弹出一个黑色窗口（已经自动定位到这个文件夹）
3. 在黑色窗口里输入下面这行，回车，等它跑完（大概 1～5 分钟）：
   ```bash
   pip install -r requirements.txt
   ```
   最后出现 `Successfully installed ...` 就成功了。

> 💡 如果下载很慢，可以改用国内镜像：
> ```bash
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

### 第 4 步：填写你的信息

1. 在文件夹里找到 `config.example.yaml`，**复制一份**，把副本改名为 **`config.yaml`**
2. 右键 `config.yaml` → **打开方式** → 记事本
3. 修改下面这几项（其他的先不用动）：

```yaml
streamer:
  name: "你的B站昵称"          # ← 改成你的 B站昵称
  room_id: 123456              # ← 改成你的直播间号
  keywords: ["你的B站昵称", "粉丝牌名"]   # ← 截图里会出现的字，填昵称和粉丝牌名

qq:
  groups: [123456789]          # ← 舰长群的群号
  admins: [10001]              # ← 你自己的 QQ 号（机器人会把需要你审核的消息发给你）

web:
  admin_password: "请改成一个复杂的密码"   # ← 后台登录密码，一定要改！
```

> ⚠️ 填的时候注意：
> - 冒号 `:` 后面要有一个**空格**
> - 引号、逗号、方括号都要用**英文**符号
> - 改完记得 **保存**（Ctrl + S）

### 第 5 步：让 QQ 小号变成机器人（安装 NapCat）

NapCat 是一个让 QQ 号能被程序控制的工具，本工具通过它收发 QQ 消息。

1. 打开 https://github.com/NapNeko/NapCatQQ/releases ，下载最新版里名字带 **`Shell`** 和 **`Windows`** 的压缩包（一键包）
2. 解压后按里面的说明启动，用 **QQ 小号扫码登录**
3. 打开 NapCat 的网页控制台（启动后黑窗口里会显示网址和 token）
4. 找到 **网络配置** → **新建** → 选 **WebSocket 客户端**，填写：
   - **URL**：`ws://127.0.0.1:8765/onebot/v11/ws`
   - **消息格式**：`Array`
   - 打开 **启用**，保存
5. 把这个 QQ 小号**拉进你的舰长群**，并设为**群管理员**

### 第 6 步：启动！

双击文件夹里的 **`启动.bat`**。

- 第一次启动会稍慢，耐心等一下
- 看到黑色窗口里出现 **`Bot xxxxxx connected`**（xxxxxx 是小号的 QQ 号），就说明机器人上线了 🎉
- ⚠️ **这个黑色窗口不能关**，关了机器人就下线了

### 第 7 步：试一试

1. 用你的大号**私聊机器人小号**，发：`改地址` —— 机器人应该会回复你
2. 用浏览器打开 http://127.0.0.1:8765/admin
   - 用户名：随便填
   - 密码：你在第 4 步设置的 `admin_password`
   - 能看到后台页面就成功了！

## 日常怎么用？

### 你（主播）要做的

| 什么时候 | 做什么 |
|---|---|
| 每次开电脑 | 先启动 NapCat，再双击 `启动.bat` |
| 机器人私聊你说「待审核」 | 打开后台，点「查看」看截图，没问题就点「**通过**」 |
| 想知道这个月情况 | 私聊机器人发 `舰长统计`，能看到谁还没填地址 |
| 准备寄礼物了 | 后台点「**导出发货表**」，用 Excel 打开 |
| 寄完一个 | 后台点「**标记已发货**」，防止重复寄 |

### 告诉舰长们怎么用（可以直接复制发群公告）

> 📢 上舰的宝宝们看这里～
> 1. 在群里发一张**上舰截图**（要能看到主播名和开通时间），机器人会自动帮你验证
> 2. 验证通过后，**私聊机器人**发「**填地址**」，打开链接填写收件人、手机号、地址
> 3. 地址或手机号要改？私聊机器人说「**我要改地址**」就行
> 4. 想看自己填的信息？私聊机器人发「**我的信息**」
>
> ⚠️ 只有**本月上舰**的舰长才能填写和修改地址哦

## 常见问题

<details>
<summary><b>❓ 黑色窗口一闪就没了 / 提示「找不到 config.yaml」</b></summary>

没有完成第 4 步。确认文件夹里有一个叫 `config.yaml` 的文件（不是 `config.yaml.txt`）。

如果看不到文件后缀：在文件夹上方点 **查看** → 勾选 **文件扩展名**，再检查文件名。
</details>

<details>
<summary><b>❓ 提示「python 不是内部或外部命令」</b></summary>

安装 Python 时没有勾选「Add python.exe to PATH」。重新运行 Python 安装包，选 **Modify** → 下一步 → 勾选 **Add Python to environment variables**，或者卸载后重装并记得勾选。
</details>

<details>
<summary><b>❓ 机器人不回消息</b></summary>

依次检查：
1. `启动.bat` 的黑色窗口是否开着，里面有没有出现 `connected`
2. NapCat 是否登录着，WebSocket 客户端的网址是否填成了 `ws://127.0.0.1:8765/onebot/v11/ws`
3. `config.yaml` 里的群号是否正确
</details>

<details>
<summary><b>❓ 截图总是识别失败</b></summary>

- 让观众发**完整、清晰**的原图，不要裁剪、不要拍屏幕
- 检查 `config.yaml` 里的 `keywords`，截图上的主播名要和这里填的一模一样
- 识别失败也没关系：观众可以私聊机器人走问答流程，或者你在后台「**手动添加舰长**」
</details>

<details>
<summary><b>❓ 观众打不开填地址的链接</b></summary>

默认的链接 `127.0.0.1` 只有**你自己的电脑**能打开。要让观众用手机打开，需要下面「让观众随时能填地址」里的方法之一。
</details>

<details>
<summary><b>❓ 提示端口 8765 被占用</b></summary>

用记事本打开文件夹里的 `.env` 文件，把 `PORT=8765` 改成别的数字（比如 `8777`）。同时记得把 `config.yaml` 里的 `public_url` 和 NapCat 里的网址也改成同样的数字。
</details>

<details>
<summary><b>❓ 有人冒充舰长怎么办？</b></summary>

机器人已经做了这些防护：
- 同一张截图不能被两个 QQ 用
- 同一个 B站账号每个月只能绑定一个 QQ
- 会去 B站 核对真实的舰长名单
- 拿不准的（比如没有截图）一律交给你人工审核，不会自动通过

有可疑情况时机器人会私聊提醒你。
</details>

## 让观众随时能填地址（进阶）

观众要用**自己的手机**打开填写链接，所以这个工具需要能从外网访问。两种办法：

| 办法 | 适合谁 | 怎么做 |
|---|---|---|
| **内网穿透**（简单） | 先试试看 | 用 [cpolar](https://www.cpolar.com/) 等工具把电脑的 8765 端口映射出去，把它给你的网址填到 `config.yaml` 的 `public_url`。缺点：电脑关机时观众填不了 |
| **云服务器**（推荐长期用） | 想 24 小时在线 | 租一台云服务器（Windows 系统最简单），把整个文件夹和 NapCat 都放上去，按上面同样的步骤运行，在服务器的安全组里开放 8765 端口，`public_url` 填 `http://服务器IP:8765` |

## 🔒 隐私提醒（很重要）

舰长的手机号和地址是**个人隐私**，请务必：

- 后台密码设得复杂一点，**不要告诉别人**
- 所有数据都在文件夹里的 **`data`** 文件夹中：**定期备份**，但**不要发给别人、不要上传到网上**
- 礼物寄完后，可以考虑定期清理很久以前的地址
- 如果你 fork / 修改了这个项目并上传到 GitHub，**不要上传 `config.yaml` 和 `data` 文件夹**（本项目的 `.gitignore` 已经默认排除了它们）

<details>
<summary>给懂技术的朋友：技术栈</summary>

- QQ 机器人：[NoneBot2](https://nonebot.dev/) + OneBot V11 协议（通过 [NapCat](https://github.com/NapNeko/NapCatQQ) 接入，反向 WebSocket）
- 网页：FastAPI + Jinja2，和机器人运行在同一个进程

- 舰长名单：B站直播公开接口 `guardTab/topList`（无需登录）
- 数据存储：SQLite（`data/guard.db`）
</details>
